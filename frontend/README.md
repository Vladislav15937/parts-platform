# Приёмка с телефона

PWA для склада: приёмка запчастей, фотографии, инвентаризация. План и решения —
`../docs/pwa-intake-plan.md`.

## Запуск

Версия Node зафиксирована в `.nvmrc` — 22 LTS. nvm поставлен через brew,
и ему нужны две строки в `~/.zshrc`, иначе `nvm` не найдётся в новой оболочке:

```bash
export NVM_DIR="$HOME/.nvm"
[ -s /opt/homebrew/opt/nvm/nvm.sh ] && . /opt/homebrew/opt/nvm/nvm.sh
```

Дальше обычное:

```bash
nvm use              # берёт версию из .nvmrc
npm install
npm run dev          # http://localhost:5173
```

Бэкенд должен работать на `:8080` — Vite проксирует на него `/api`. Прокси
обязателен, а не удобен: сессия живёт в cookie, а CSRF-токен приложение читает
из cookie скриптом, и то и другое работает только на одном источнике.

## Что уже есть

Каркас: вход, проверка живой сессии при старте, признак связи, Service Worker
для офлайн-старта оболочки. Экранов приёмки пока нет — см. §6 плана.

Проверено: `tsc --noEmit` без ошибок, `vite build` собирается, dev-сервер отдаёт
страницу, Service Worker и манифест попадают в `dist`, прокси доносит `/api`
до бэкенда. Живого сквозного входа через браузер ещё не было — только через
MockMvc на стороне бэкенда.

## Два места, в которые стоит смотреть

**`src/api/client.ts`** — деление ошибок на постоянные, временные и «сессия
потеряна». На нём будет стоять очередь отправки: повторять можно только
временные, иначе одна битая запись забьёт очередь вечными повторами.
Ради этого различения на бэкенде появился `ApiExceptionHandler`.

**`public/sw.js`** — API не кэшируется никогда. Закэшированный ответ склада
означает, что продавец видит деталь, которой нет. Поэтому Service Worker
написан руками, а не сгенерирован плагином: запрет должен быть виден.

## Чего здесь нет намеренно

- **Роутера.** Экранов два, и переход определяется не адресом, а тем, вошёл ли
  человек. Появится вместе с экранами приёмки.
- **Библиотеки состояния.** Пока состояние — это сессия; `useState` хватает.
- **Иконок в манифесте.** Нужны настоящие, а не заглушки: браузер отказывается
  ставить приложение с битыми иконками, и лучше пустой список, чем ссылки
  в никуда.
