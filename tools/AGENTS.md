# Codex: инструменты

Общие инструкции — корневой `AGENTS.md`. Перед правкой или запуском
инструмента прочитай его заголовок и запусти из корня
`python3 tools/codex-context.py tools/<имя>`; прочитай выбранные правила
`.claude/rules/` (в том числе правила часов и дымовых проверок).
Выполняй документированную самопроверку изменённого инструмента.
Подделки доказательства — только `.scratch/`, по `docs/agent-workflow.md`.
Сохраняй exit code исходных команд. Не печатай секреты или полные настройки auth.
