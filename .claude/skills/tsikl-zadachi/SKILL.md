# Цикл одной задачи

0. **`./tools/can-start.sh`** — не строим ли на сломанном. Красная `main` —
   стоп для всех. Звать без пайпа: код возврата принадлежит сторожу.
1. **Ветка `feature/N`** от свежей `main`. Одна задача — одна ветка.
2. **Найти правило, а не симптом.** Почти всё, что выглядит ошибкой,
   нарушает правило, которое надо назвать.
3. **Тест, который падает до правки.** Не после — до.
4. Правка.
5. **Полный набор:** `./mvnw -o test`, `cd frontend && npx vitest run`.
6. **Живой прогон**, если правку видит человек: `./tools/dev-up.sh`.
7. **PR с доказательствами:** что нашёл, чем доказал, чего не тронул.
8. **Зелёный CI — и только тогда слияние.**

Подробности и исключения — `docs/agent-workflow.md`. Там же, в разделе
«Чего разбор не касается», критерий: правка без единой строки кода и теста
сливается без разбора. Расширять этот список самому нельзя.

**Вердикт принадлежит той голове, про которую спросили,** и умирает на её
следующем сдвиге: `./tools/head-green.sh <SHA>` — ноль зелёная, единица
красная, двойка «ответа нет». Один зелёный прогон из двух — не вердикт.
