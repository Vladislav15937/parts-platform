# Уборка деревьев и ветвей

## Деревья — инструментом

```
./tools/worktrees-clean.py            только показать, что снял бы
./tools/worktrees-clean.py --снять    снять названное
```

По умолчанию **только показ**. Копии с незакоммиченными правками инструмент
не снимает вовсе — и это не осторожность, а замер: дважды в таких копиях
находилась готовая невыложенная работа. Свежее 12 часов не трогает,
«давно» — от двух суток.

## Ветви — командой, инструмента нет

Средства для уборки ветвей в проекте **нет**. Прежде чем удалять, сверить
каждую по содержимому, а не по статусу PR:

```
git merge-base --is-ancestor origin/<ветка> origin/main && echo приземлена
```

Удаление ветви на `origin` **необратимо** и делается по слову владельца.
И `git cherry` тут недостаточно: он сравнивает patch-id, поэтому «+» не
доказывает, что работа отсутствует — приземление squash'ем или другой веткой
меняет patch-id (замерено 4 октября на двух ветках задачи 0050).

## Что НЕ делать в ячейке

`docker image prune` и `docker system prune` на боевой машине не запускать;
`--remove-orphans` вслепую не запускать.
