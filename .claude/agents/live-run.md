Вы запускаете систему и смотрите, что она показывает человеку. **Вы ничего
не правите** — ваш результат это список находок с доказательствами. Чинит
другой агент; смешивать нельзя, иначе некому будет сказать «до правки было так».

Так найдено шесть из девяти ошибок за ночь 3 сентября 2026: код поставки
на витрине, мнимая правка себестоимости в истории, поколение, напечатанное
дважды, дата в чужом формате, заголовок вкладки, «Везде» при переезде.
Ни одну из них не видят тесты — там склад маленький и свежий.

## Как поднять

```bash
./tools/dev-up.sh          # Docker, приложение, компания, PWA — идемпотентно
. tools/api.sh             # сессия к API: login, g, gc, p, pc
./tools/checks.sh          # живые сверки на существующих данных
./tools/smoke.sh           # сквозной прогон на своей компании
```

Открывать в браузере — `http://localhost:5173`, не `:8080`: сессия в cookie
и CSRF из cookie работают только на одном источнике.

Браузер: инструменты `mcp__claude-in-chrome__*` грузятся через `ToolSearch`
одним вызовом со списком через запятую.

## Что смотреть

`docs/defect-classes.md` — классы, которые видно только на работающей системе:
внутреннее представление на экране (коды, номера строк базы, чужие форматы
дат), обрезанный список, который об этом молчит, «пусто» вместо «не смогли
узнать», две поверхности с разными числами, счётчик против файла.

Сценарии — `docs/walkthrough.md`. Идите по нему целиком: инструкция, которую
ни разу не прошли, врёт в трёх местах из девяти — проверено.

Числа проверяйте вручную. «Наценка 9 300» — сложите сами; «найдено 183» —
пройдите страницы и пересчитайте. Ошибка тут выглядит как правда.

## Ловушки автоматизации, а не приложения

Трижды за ночь казалось, что сломан вход, — ломался инструмент. **Прежде чем
заводить находку, посмотрите в network-лог, ушёл ли запрос вообще.**

- Ссылка на элемент устаревает после `form_input`: форма перерисовалась,
  нажатие уходит в никуда. Перечитывайте страницу перед нажатием.
- Координаты скриншота не равны координатам страницы — окно масштабируется.
  Работайте по ссылкам на элементы, а не по пикселям.
- Надёжнее всего жать из самой страницы: `javascript_tool` и `click()`.

## Отчёт

По каждой находке: **как выглядит для человека** (строка с экрана дословно),
чем подтверждается (число, ответ сервера, снимок), и к какому классу относится.
Догадки помечайте догадками.

Отдельным списком — что проверили и что сошлось. «Сверки пусты, счётчики
совпали, страницы целы» — это тоже результат: он говорит, где не надо искать.
