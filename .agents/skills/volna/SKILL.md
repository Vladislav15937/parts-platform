# Приземление волны в Codex

Применяется для уже разрешённой человеком волны, не запускает её самостоятельно. Порядок, счёт выкидываний, полный SHA и условия слияния остаются исходными. В Codex worktree выделяется явно до запуска агента. Используй доступные инструменты сообщений и ожидания; их имена Claude не считаются командами Codex.

До исполнения прочитай `docs/codex.md` и каноническую процедуру
`.claude/skills/volna/SKILL.md` целиком, затем следуй ей с переводом
механизмов Codex из этого документа. Все пути — от корня репозитория.

Исходный frontmatter Claude не настраивает Codex. Ссылки не загружают
содержимое автоматически; используй чтение файлов. Если вывод обрезан,
дочитай оставшиеся части. Не считай наличие процедуры результатом проверки.
